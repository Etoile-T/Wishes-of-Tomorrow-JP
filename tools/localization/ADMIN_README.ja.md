# ローカル翻訳管理画面

このMacだけで使う、Python標準ライブラリ製の管理画面。外部API・アカウント・追加パッケージは不要です。

## 起動

`tools/localization/start-admin.command` をダブルクリックするか、リポジトリのルートで実行します。

```sh
python3 tools/localization/admin.py
```

ブラウザで <http://127.0.0.1:8766> を開きます。終了はターミナルで Control+C。
既に起動している場合は同じURLを開いてください。別のポートは `--port 8767` で指定できます。
待受は127.0.0.1だけで、LANやインターネットへ公開しません。

訳稿・メモは `../artifacts/translation-admin/drafts.sqlite3` に保存します。
ブラウザを閉じても、サーバーを再起動しても残ります。移行・退避時はサーバーを終了して、このフォルダ全体をコピーしてください。
`--storage PATH` で保存先を変えられます。DB・バックアップをGitに追加しないでください。

## できること

- カタログ全61,722行の原文・反映済み訳文を表示。未翻訳も含む。
- 12種類、マップ、状態で絞り込み。ID・ファイル名・原文・訳文・訳稿・メモを検索。
- メッセージの全行を確認しながら制御コード付きの訳稿・メモを保存。
- 既存の用語辞書を参照。自動翻訳や外部送信はしない。
- 保存した訳稿をチェックボックスで最大500行選択し、ID付きJSONを出力。
- 制御コード・変数・収録グリフと現在のソース位置を既存の検査コードで照合。
- 条件を満たす未翻訳の通常会話は、バックアップを取ってソースへ反映。

分類は種類別Excelと同じファイル・フィールド規則を使用。カタログ外のトレーナー名・マップ名707件は対象外で、既存Excelで参照できます。未使用・重複・記号だけの候補も含むため、未翻訳数は実プレイの残り会話数ではありません。

## 編集・出力

1. 一覧をクリックし、原文と「同じメッセージの行」を確認。
2. 訳文欄に制御付きの生文字列を入力。実改行ではなく `\n`、改ページは `\p`、スクロールは `\l`。変数・制御・終端 `$` は保持。
3. 「訳稿を保存」。この段階ではゲームソースを変更しない。編集中の未保存内容は移動前に警告する。
4. 意味・人物の口調を見直したら「原文の意味・口調を確認済み」にチェックして再保存。
5. メッセージ全行を選択し、「選択した訳稿を検査」。ソースへ反映できない種類も理由を表示。
6. JSON出力は未検査の訳稿も含められる。出力は検査合格やyomiyasuレビュー済みの証拠ではない。

既存の英語版からの文字位置・IDを維持します。カタログは再抽出しません。
翻訳済み行の修正や固定長UIは、JSON出力後に専用の文字数・レイアウト検査を通し、既存の `update_catalog.py` の手順で適用してください。

## 管理画面からのソース反映の範囲

対象は `data/maps/` または `data/text/` 内の未翻訳script行のみ。
メッセージの全行に保存済み・レビュー済みの訳稿が必要です。既存翻訳を含む混在メッセージ、C文字列、固定長UI、点字を含むファイル、プリプロセッサ分岐を含むファイルは管理画面からの反映を止めます。

全行をつないだ日本語モード、名前変数の英語モード、末尾の英語モード復帰、26マス以内の幅を追加検査します。幅は既存 `dialogue_tools.cells` と同じ保守的な推定です。
ソース照合と適用計画は `update_catalog.plan` を利用。検査後に訳稿・レビュー状態・カタログ・対象ソースが変われば反映を拒否します。

反映時に `../artifacts/translation-admin/backups/日時-ID/` に原ソース、カタログ、進捗、適用バッチを保存します。書き込み失敗時には既に変更したファイルを戻します。反映済みの訳稿はDBから取り除き、カタログの翻訳済み行として表示します。
`status.json` の件数を更新し、ビルド状態をstale、Excel再生成を必要と記録します。現在のROMのパスは保持し、ROM・セーブは書き換えません。

ソース反映後は **AGENTS.md / HANDOFF_CODEX.md のyomiyasuレビュー・検査・コミット・新規OBJ_DIRでのビルド・パッチ照合・Excel再生成・進捗更新・push** を実施してください。管理画面はこれらを自動実行しません。確認用プレビューはゲームのフォント・ウィンドウの再現ではなく、プレイ検証の代わりにもなりません。

バックアップから戻す場合はサーバーを停止し、他の編集がないことをGit差分で確認してから、バックアップにある対象ファイルだけを戻します。以後の別の翻訳まで上書きしないでください。
