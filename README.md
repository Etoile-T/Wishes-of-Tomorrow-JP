# Pokémon: Wishes of Tomorrow 日本語版

『Pokémon: Wishes of Tomorrow』の非公式日本語化プロジェクトです。
ストーリー・会話、ポケモン関連データ、メニューなど、**カタログに登録した61,722件の翻訳データを反映済み**です（2026-10-27）。

**Codex・Claude Codeを使用した機械翻訳です。** 参考フォークの日本語訳や公式名称も利用しています。人手による全編校閲と、ゲームを最初から最後まで遊んでの確認は終わっていません。誤訳、不自然な表現、表示崩れなどが残る可能性があるプレビュー版です。

## 入手する

配布場所は [GitHub Releases](https://github.com/Etoile-T/Wishes-of-Tomorrow-JP/releases) です。ROM本体は配布せず、BPS形式の差分パッチを配布します。

**現在、61,722件版のBPSはリリース下書きとして準備中で、一般公開前です。** 公開後は対象リリースの「Assets」から `wishes-jp-preview-61722-bps.zip` をダウンロードしてください。「Source code」のZIPはゲーム本体やパッチではなく、開発用ソースコードです。

## 遊び方

### 1. 対応する英語版ROMを確認する

**現在のBPSは、ソースからビルドした英語版Wishes専用です。市販エメラルドROMや、公式1.2.6パッチ適用後のROMには使えません。**

| 適用元ROMの条件 | 値 |
|---|---|
| 種類 | このプロジェクトの基準となる英語版Wishesのソースビルド |
| サイズ | 32 MiB（33,554,432バイト） |
| CRC32 | `62ba561e` |
| SHA256 | `93fb28460bb7348e327c97e217ecd50091fc01200e8d9cc41b871469c36c9db7` |

ファイル名だけでは対応を判断できません。チェックサムが一致することを確認してください。対応ROMを用意できない場合、このBPSは使えません。開発環境を用意できる方は、下の「ソースからビルドする」を利用できます。

### 2. BPSを適用する

公開後の配布ZIPには、BPS・説明書・`manifest.json`・チェックサム一覧が入ります。

1. ZIPを展開します。
2. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/) など、BPS対応のパッチツールを開きます。
3. ROM欄に上記と一致する**英語版ROM**、パッチ欄に同梱の `.bps` を指定します。
4. パッチを適用し、元のROMとは別の名前で `.gba` を保存します。

「ROMが違う」「チェックサムが一致しない」と表示されたら、適用元やパッチの版を確認してください。不一致を無視して適用しないでください。日本語版ROMにさらにこのBPSを重ねる必要はありません。

61,722件版の適用後SHA256:

```text
310c35cbc1e3e9563b81ab6420843a342e7c8d83437c387c65be1e9218e712bf
```

### 3. ゲームを起動する

作成した `.gba` を、mGBAなどのGBA対応エミュレータで開きます。キーボード・コントローラーの割り当ては、使用するエミュレータの設定を確認してください。

すでに日本語版の `.gba` を手元に用意している場合は、パッチ適用を省略してそのファイルを開いてください。

### 4. 更新版へ切り替えるとき

旧ROMとセーブデータをバックアップし、新しいROMは別名で保存してください。別の版で作ったステートセーブを読み込まず、新しいROMを起動し直してください。既存のゲーム内セーブとの互換性も未検証です。

## 対応状況

実装・翻訳データへの反映と、ゲーム内での確認を分けて記載しています。

### 実装・翻訳データ反映済み

- [x] ストーリー・イベント・NPC会話の翻訳（カタログ登録範囲）
- [x] ポケモン名・技・特性・道具・図鑑の翻訳（カタログ登録範囲）
- [x] 戦闘・メニュー・設定・クエスト等のテキスト翻訳（カタログ登録範囲）
- [x] ひらがな・カタカナのフォントと文字描画処理
- [x] 日本語の名前入力
- [x] 日本語版GBAのビルドとBPS作成・再適用照合

記号・制御コードのみの文字列・識別子・スタッフ名・一部の固定長バッファなどは、意図的に英語のまま残しています。カタログの未翻訳0件は、未抽出の文字列や画像内文字まで含めた完全日本語化を示すものではありません。

### 残っている作業

- ゲーム内の表示、戦闘・イベント進行・保存の通し確認
- 長い技名、戦闘文の所有格部品などの表示確認・調整
- 訳文の全編校閲と、口調・用語の統一確認
- 画像内に描かれた英語の調査・日本語化
- 漢字表示への対応
- BPSの一般公開（現在は下書き）

最新の検証記録では、ビルド・83件の自動テスト・BPS再適用後のROM照合が成功しています。これらはゲーム全編の正常動作を保証するものではありません。

## 不具合・誤訳を報告する

[Issues](https://github.com/Etoile-T/Wishes-of-Tomorrow-JP/issues) に、以下を添えて報告してください。

- 使用した版名・BPSのファイル名
- 場所、人物、画面名
- 不具合が出るまでの操作、実際の表示内容
- スクリーンショット、使用したエミュレータとバージョン

誤訳の報告は「現在の訳」と「気になる点」だけでも構いません。公開IssueにROMやセーブデータを添付しないでください。

## ソースからビルドする

開発環境の準備は [元プロジェクトのドキュメント](docs/README.upstream.md)、日本語版固有の手順は [開発記録](localization/README.ja.md) を参照してください。現在のソースには翻訳データが適用済みです。

ビルドする場合は、既存のROMや中間ファイルを上書きしないよう、版ごとに新しい `FILE_NAME` と `OBJ_DIR` を指定してください。開発の詳細は [引き継ぎ資料](HANDOFF_CODEX.md) と [機械可読の進捗](localization/status.json) にあります。
