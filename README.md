# Pokémon: Wishes of Tomorrow — 日本語化プロジェクト

『Pokémon: Wishes of Tomorrow』を日本語で楽しめるようにすることを目的とした、非公式の日本語化プロジェクトです。

オリジナル版のゲーム内容や独自システムを維持しながら、ストーリー、イベント、メニュー、ポケモン関連データなど、ゲーム全体の日本語対応を目指しています。

> **開発状況：日本語化作業中（WIP）**
>
> カタログに登録された61,722件はすべて翻訳状態を登録済みです（2026-10-27）。
> 実ゲームでの表示・進行・保存の検証は未完了で、完成版ではありません。

## 日本語化の対象

本プロジェクトでは、以下の要素の完全日本語化を目標としています。

- メインストーリー、イベント、NPCの会話
- ポケモン名、技名、特性名、道具名
- ポケモン図鑑および各種説明文
- 戦闘メッセージ、メニュー、設定画面
- クエスト、チュートリアル、独自システム
- タイトル画面、画像内の英語テキスト
- クリア後のイベントおよび追加コンテンツ

また、ひらがな・カタカナ・漢字を適切に表示するため、日本語フォントや文字描画処理の対応も進めます。

## 翻訳について

**本プロジェクトの日本語訳は、生成AI（Codex・Claude Code）を使用した機械翻訳です。**
参考となる日本語対応フォークの訳文や公式名称も利用し、原文との照合・表記調整・自動検査を行っています。ただし、人手による全編の翻訳・校閲を終えたものではありません。誤訳、不自然な表現、口調や用語の不統一が残る可能性があります。

気になる訳や表示の不具合があれば、場所・原文や表示内容・使用した版を添えて報告してください。

## 開発方針

本プロジェクトでは、オリジナル版の仕様を尊重し、ゲーム本来の体験を損なわないことを重視しています。

翻訳は原文の意味や登場人物の個性を維持しながら、自然で読みやすい日本語になるよう調整します。

日本語化に伴うUIの表示崩れや文字化けを修正し、ゲーム全体を通して快適にプレイできる状態を目指します。
